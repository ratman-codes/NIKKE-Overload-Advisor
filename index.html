Custom (temporary) locks hold a line for one reroll and save modules — great for batching value resets. Unlocking never refunds modules.

The two reroll buttons & key definitions
  • Change Effects — rerolls the effect types on every unlocked line (values change too). Use this to fish for the stats you want.
  • Reset Attributes — rerolls only the value % of existing effects on unlocked lines; types stay, empty lines stay empty. Use this to push a good stat above its minimum.
  • Blue line = Tier 12–14 (rare, high value). Black line = Tier 15 (highest, ~1% — basically never reroll these away).
  • Lock a good line before Change-Effects fishing so you don't lose it. Locking Line 1 is discouraged unless it's Blue/Black, because Line 1 always rolls something anyway — you'd rather keep it free and fill it last.
