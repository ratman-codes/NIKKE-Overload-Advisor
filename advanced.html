The two reroll buttons and key terms
  • Change Effects rerolls the effect type on every unlocked line (values change too). Use it to find the effects you want.
  • Reset Attributes rerolls only the value of each unlocked line. Types stay, empty lines stay empty.
  • Value rule since the Oct 2026 patch: a reset never repeats a line's current value. Rolling from a Phase 1 to 5 value makes every other value about 14% more likely; rolling from Tier 11 or higher gains nothing. Black from a Phase 1 to 5 value takes about 88 resets (99 from Tier 11+); Blue or better about 22 (25). When hunting Blue or Black, accept only the target tier. A Phase 6 to 10 value is only about 6% worse than Phase 1 to 5, so keep good mid rolls. If you stop early, take the best value offered; re-parking later costs about 2 rolls. Change Effects is unaffected.
  • Blue line = Tier 12 to 14. Black line = Tier 15 (about 1% per roll).
  • Lock a good line before fishing with Change Effects so you keep it. Avoid locking Line 1 first unless it is Blue or Black: Line 1 always rolls something, so fill it last.
  • Temp locks hold a line for one reroll. Good for short holds, such as protecting a Line 1 roll for one spin. For long fishing on Lines 2 and 3 the cost adds up; the Temp locks switch in section 3 shows it.
  • CP tip: the first overload roll is always Tier 11 and option ranks feed combat power, so for a supporter you only want CP from, leaving the initial rolls alone can be the best choice.
  • What you fish last decides the cost. Community lock-order sims (Pesu My): plans that end on Line 1 (100% appearance) cost about 55 to 58 modules, plans that end on Line 2 (50%) 70 to 83, and plans that end on Line 3 (30%) 102 to 107. Locking a lone Line 2 early costs only 2 to 3 modules more than the chart's keep rolling. Leaving Line 3 for last roughly doubles the bill.

A wanted effect lands on Line 2 below Blue. What now?

  • Effects first, then values together. Lock each effect as it lands, whatever its value. Once every effect is on the piece, unlock the ones below target (free) and reroll values with all of them in play. Each reset rolls every unlocked line at once, so more lines in play means more chances per module. Lock each line when it reaches its target. Raising a value before locking costs the same at Prydwen minimums and about 25% more for Blue or Black targets.
  • Keep rolling (3→2→1) is cheapest by 2 to 3 modules: rolls stay at 1 module, and a worse roll can always be declined with Keep.
  • Lock Line 2 now (2→3→1) costs those 2 to 3 modules and keeps the value. Below the minimum, keep rolling. Tier 8 to 11, either is fine; the higher the tier, the better the lock. Tier 12 and up, lock.
  • Both plans fish Line 1 last, which is why they cost about the same. The expensive mistake is leaving Line 3 for last.
